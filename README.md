# plexityper

Experiments and a draft manuscript on **host-optional microbial assemblages** ("plexibionts") and
**plexitrophy**: obligate nutritional dependence that is irreducibly spread over more than one
partner. The work is done by a small multi-agent team (Claude, Codex/GPT and Gemini), with a human
lead. Each result is reviewed by an agent from a different model family than its author.

## Layout
- `protocols/`: pre-registered experiment protocols. Each is frozen, with its hash posted, before it runs.
- `discussion/`: concept review and deep theory notes.
- `alife/`: artificial-life simulations used for prediction by synthesis.
- `scratch/`: scorers, pipelines and job scripts.
- `results/`: outputs with provenance. Only synthetic or non-sensitive results are published here.
- `notes/`: per-agent working notes.
- `logs/`: dated activity logs.

## Not in this repository
Raw and unpublished data (`data/`), collaborators' data, real-sample results that carry sample
coordinates, copyrighted papers, and local infrastructure are kept off GitHub on purpose.

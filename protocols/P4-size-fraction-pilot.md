# P4 draft protocol · Amundsen HS22-003 size fractions

**Status:** Discussion draft for Carbon’s cross-family review and grid’s decision. No sequence data or MAG results were examined in drafting this protocol. The inputs were identified from sample metadata and file existence.

**Question.** In one water collection, can we estimate the fraction of predicted nutritional requirements that require multiple microbial partners, with comparable genome recovery across size fractions? The directional hypothesis for a later replicated study is that this proportion increases on the coarse filter. The pilot has one biological event. Its deliverables are an auditable denominator, a descriptive within-event contrast, and a decision about whether the comparison is identifiable.

## Measurement after approval

1. Use the same fixed reference catalogue, dereplication, mapping and annotation versions for all three libraries. Use only one DAS Tool consensus bin set, then dereplicate at 95% ANI with skani and retain the same representatives across fractions. Record assembly, bin-to-contig assignments and cluster membership. Raw binners can assign overlapping contigs to multiple bins. Filter the per-MAG annotation and coverage tables to these representatives. Prefer existing danaSeq outputs with matching provenance. If new mapping is necessary, record paired reads received, retained, mapped uniquely, ambiguous and unmapped, plus genome breadth and depth by library. Proposed primary detection threshold is 50% genome breadth. Repeat with 70% breadth and equal read-pair subsampling to the smallest retained library. Report how many units change status. Also subsample to a common number of uniquely prokaryotic-mapped read pairs, using the same catalogue, pair-assignment rule and fixed seed across fractions. Recompute breadth and support calls after each subsampling. Report prokaryotic, eukaryotic, other and unassigned pair counts out of all retained pairs where a suitable classification is available. Unmapped reads have unresolved origin. Report reference bias and any fraction with too few pairs to score. These checks address sequencing effort and dilution of prokaryotic coverage separately.
2. Use the versioned recipient rules and external-resource scenarios from the reviewed P2 protocol; record its hash before scoring. Require MAG completeness ≥90% and contamination ≤5% for assignment. Keep incomplete recovery, unbinned candidate donors and alternative pathways explicit. Evaluate all feasible donor sets and wirings for one recipient endpoint under one fixed supply scenario. A supported requirement qualifies if every feasible minimal wiring requires at least two immediate donors or a focal strongly connected component of at least three organisms. Missing or incomplete enumeration is unresolved. Score ambient rescue separately. Results describe modeled dependence.
3. The unit is one dereplicated recipient MAG × one prespecified nutritional requirement × one fraction under one scenario. Collapse alternate donors and synonymous annotations for the same requirement to one row. Print a flow table per fraction from detected MAGs to quality-eligible MAGs, evaluable endpoint calls and candidate auxotrophies. Count autonomous outcomes separately. Among candidate auxotrophies, retain eligible unresolved support calls in the denominator. Let N be this total, K the qualifying calls and U the unresolved calls. The descriptive identified range is K/N to (K+U)/N. An empty denominator is unestimable. Partition U by the first applicable reason: ambiguous evidence (including partial routes, unbinned candidates or ambiguous mapping), no detected feasible donor under the stated scenario after complete enumeration, or other unresolved calls such as incomplete enumeration. Report mutually exclusive counts summing to U. An empty donor set leaves the source unknown. If the scenario explicitly supplies the requirement in the environment, record a resolved zero-donor rescue separately, retaining that recipient in the fixed candidate denominator across scenarios. Give counts alongside proportions.
4. Condition on genome size using a primary paired comparison restricted to recipient–endpoint identities recovered in both primary fractions from the same fixed MAG catalogue. This matches genome size, lineage and endpoint exactly. Retain unresolved calls in the ranges. Report the loss of fraction-exclusive recipients, the shared denominator, and unadjusted counts for each fraction. This estimates a difference in *potential donor availability around shared recipients*; fraction-exclusive community composition is a separate descriptive outcome. Matching within one event cannot balance environmental conditions across events.

## Interpretation and decision

For the matched coarse and fine sets, report coarse minus fine with bounds from lower coarse minus upper fine to upper coarse minus lower fine. An interval entirely positive is directionally consistent **in this collection**; entirely negative gives the opposite ordering; an interval touching zero leaves the direction unresolved. These are missing-data bounds, not confidence intervals. If detection sensitivity reverses the direction, report sensitivity-dependent ordering. Missing field confirmation, unsupported pathway rules or no common eligible recipient–endpoint calls leave the primary comparison unestimable. No significance test over MAGs, read pairs or filters can substitute for independent collection events.

A feasible measurement motivates replication across separately collected events with verified filtration and prespecified blocking by station or cruise. A single comparison cannot establish general particle enrichment, flux, cellular proximity or a discrete plexon. For another dataset, the ASGARD amplicon series can test taxonomic fraction associations; its 16S records cannot supply MAG-specific nutritional endpoints. No cluster submission or fresh assembly is part of draft preparation.
